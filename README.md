## The project in a nutshell

The proposed research develops an efficient, learning-based sensing
framework for 5G/6G Integrated Sensing and Communication (ISAC) networks.
Using signals a cellular network already transmits, the framework detects,
localises, and tracks objects — demonstrated on aerial targets, but
target-agnostic by design. The two main contributions are a learning-based
method for choosing *which* receivers to use, and a robust method for
tracking multiple targets over time.
